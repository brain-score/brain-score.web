The lab toolbox Preview 
# Install (Python 3.11)
pip install brainscore

# Score one participant on one experiment
import brainscore
brainscore.score('resnet50', 'MajajHong2015public.IT-pls')
# Images, sentences, sounds or video: the column says which
stimuli = StimulusSet({
    'stimulus_id': ['cat', 'dog'],
    'image_path': ['cat.png', 'dog.png'],
})
# Record any layer as a brain region
participant = brainscore.load_model('resnet50')
participant.start_recording(['V4', 'IT'])
activity = participant.process(stimuli)
# Choices, ratings or free text, with reaction times
task = TaskContext(response=Choice(
    ['animal', 'vehicle'],
    reaction_time='evidence_margin'))
# Silence units, observe the effect, then undo it
lesion = StateChange(kind='ablation',
    target=Selection(layer='layer4', indices=units),
    perturbation=Perturbation(kind='zero'))
# Games, simulators and robot tasks
with EnvironmentSession(Corridor()) as session:
    agent.participate(session)
    actions = session.collect('motor')
# Conditions, repetitions and recorders in one saved record
experiment = Experiment(subject=participant,
    protocol=TaskProtocol(stimuli, task),
    tools=[RecordNeural(['IT']), RecordBehavior()])

One toolbox for every participant.

Present stimuli, record activity, ask for answers, silence units, or place a participant in a game or a robot task. The same tools work on a vision network, a language model, a vision-language model or a robot policy. Run them on your own machine, and add new participants and experiments openly.
